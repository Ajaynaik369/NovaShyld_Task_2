# NovaShyld Task 2 — Web Exploitation & Vulnerability Analysis

## Objective
This repository contains the submission for Task 2 of the NovaShyld Bug Bounty Internship Program.

The objective was to:
- Perform web application vulnerability testing
- Exploit common web vulnerabilities
- Document findings professionally
- Demonstrate proof-of-concept exploitation

---

## Vulnerabilities Demonstrated

### 1. Reflected Cross-Site Scripting (XSS)
- Payload injection
- JavaScript execution
- Burp Suite interception

### 2. Insecure Direct Object Reference (IDOR)
- Parameter manipulation
- Unauthorized resource access
- Access control weakness

---

## Tools Used
- Burp Suite Community Edition
- Browser DevTools
- PortSwigger Web Security Academy

---

## Repository Structure

- screenshots/ → Exploitation screenshots
- payloads/ → Payloads used during testing
- burp_requests/ → Raw HTTP requests
- Task2_Report.pdf → Final vulnerability report
- videos/ → Walkthrough video link
